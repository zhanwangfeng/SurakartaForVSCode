# Surakarta for VS Code

在 VS Code 中下苏拉卡尔塔（Surakarta）棋：5×5 格 = 6×6 交点，每方 12 子，四角同心双弧。

## 功能

- 左侧活动栏「Surakarta」入口
- TreeView 菜单选择对战模式：
  - **双人对战**：两名玩家轮流落子
  - **人机对战**：与 AI 对战，含简单 / 普通 / 困难三档（搜索层数 2 / 3 / 4）
- Webview 游戏主体（照抄自 `demo/index.html`）

## 规则简介

- 普通走子：每回合选一枚己方棋子，向八方向走一格到空点。
- 吃子：只能沿弧线箭头方向绕行（不可逆向）；滑行路径上若先碰到己方棋子则不能吃子，若先碰到对方棋子则吃掉该子（只吃第一个碰到的对方棋子）。
- 胜负：一方棋子被吃光则另一方获胜；若双方均无法再吃子，则剩余棋子多者获胜。

## 开发

```bash
npm install
npm run compile   # 或 npm run watch
```

按 F5 启动扩展开发宿主进行调试。
